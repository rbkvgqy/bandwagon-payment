**国家选 China，邮箱用真实的。** 邮箱是登录账号，服务器 IP、SSH 端口和 root 初始密码都发到这里。姓名、城市、手机号随便填，不做实名验证，但邮箱这栏糊弄不得。

## 银联支付，支付宝报错时的备用通道

银联通道同样走人民币：结算时选 Unionpay，跳转到银联页面后输入国内银行卡号付款；习惯网银的话，页面里还有网银支付入口，跳转到对应银行的页面完成。

它的真正价值在兜底。支付宝接口偶尔会跳出“系统有点儿忙”或者 SECONDARY_MERCHANT_STATUS_ERROR 这类报错，多数是临时故障。这时候不用重新下单——订单会保留 24 小时——直接在支付方式里换成银联接着付就行。

卡种上有一点要留意：储蓄卡基本都能过，有教程提醒银联通道对信用卡不太友好，可能被拒。手边如果是信用卡且付款失败，换张储蓄卡或者干脆切回支付宝，别反复重试。也有教程提到可以用云闪付 App 扫码，看支付页当时给什么入口。
